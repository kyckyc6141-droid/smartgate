How it works — Single-runner mode, three detections in a row: 1st = Start, 2nd = Stop, 3rd = Reset back to Ready, repeating. Deciding "has it gotten closer than the threshold?" is handled directly on the Arduino; the web page only sends the threshold slider value, and the Arduino fires a single event only at the moment the distance crosses that threshold. An object staying within range won't re-trigger repeatedly — it has to leave the range and re-enter for the next event to count.

Note — Web Bluetooth only works in Chrome/Edge (desktop or Android); Safari/iOS is not supported. It only works over HTTPS or localhost (opening the file directly via file:// disables the connect button). The SERVICE_UUID/CHARACTERISTIC_UUID in the Arduino sketch must exactly match this page for the connection to work.
